# 作品集在线演示站 · 深色毛玻璃风格

面向面试演示的 UI/UX 作品集网页。**纯静态、零依赖、零构建**，双击 `index.html` 就能看，
所有排版与素材通过一个配置文件管理，替换作品图不需要改代码。

---

## 一、快速开始

| 方式 | 操作 | 说明 |
| --- | --- | --- |
| 最简单 | 双击 `index.html` | 直接可用，推荐面试前本地预览 |
| 本地服务 | 在本目录命令行运行 `python -m http.server 8000` | 浏览器打开 `http://localhost:8000` |
| 部署 | 整个 `portfolio` 文件夹丢到任意静态托管（如 Vercel / Netlify / 对象存储静态托管） | 纯静态，无需构建步骤；项目已剔除所有未被引用的素材 |

首屏只加载当前章节的 1~3 张图，其余图片滚动到可视区域才加载。

## 三、替换作品图（最常用的操作）

**当前章节与素材命名对照（Tab 角标数字自动统计）**

| Tab | 作品数 | 素材命名 |
| --- | --- | --- |
| 01 首页 | 封面 | `assets/cover/cover.mp4`（可换 .gif / .jpg） |
| 02 个人简介 | 1 | `about-01.jpg` |
| 03 一体化协同办公OA | 9 | `oa-01.jpg` ~ `oa-09.jpg` |
| 04 企业情感化运营视觉 | 2 | `visual-01.jpg` ~ `visual-02.jpg`（另含「徽章展示」标题占位，待补素材） |
| 05 移动端 App | 34 | `app-01.jpg` ~ `app-34.jpg`（全部为图片） |
| 06 网页/中后台 | 8 | `web-01.jpg` ~ `web-08.jpg` |
| 07 运营banner | 7 | `banner-01.jpg` ~ `banner-07.jpg` |
| 08 关于我 | 1（文字卡） | 无图片，在 `config.js` 的 `me` 章节里改文字与联系方式 |

合计 61 件作品 + 18 张徽章动图（首页封面与「关于我」文字卡未计入）。素材统一放在 `portfolio/`
根目录下（`visual-xx.jpg`、`app-xx.jpg` …），换图时覆盖同名文件即可。

**方式一：同名覆盖（推荐，零代码）**

把你的作品图重命名成 `app-01.jpg`、`web-05.jpg` 这样，直接覆盖 `assets/works/` 下的同名文件即可。
页面布局、文案、顺序都不会变。

**方式二：换个文件名**

在 `js/config.js` 里把 `'app-01.jpg'` 改成你的文件名即可。文件名里不带目录时，
默认到 `assets/works/` 下找；也可以写完整相对路径 `'assets/works/我的作品.png'`。

换完图刷新页面即可自检：路径写错时对应卡片会显示「素材未找到」并给出它期望的路径。

## 四、配置速查（js/config.js）

### 1. 排版类型：决定一屏放几张图

| layout | 一屏内容 | 适用范围 |
| --- | --- | --- |
| `cover` | 全屏封面：视频/动图/图片铺满整屏（纯背景，无文案） | 第 1 屏封面 |
| `cover` + `coverTitle` | 封面大标题浮层：`lines` 上下两行超大斜体重型展示字（阿里妈妈数黑体、skewX(-8°)、纯白）+ `sub` 加粗副标题署名 | 首页「2026 / PORTFOLIO」 |
| `single` | 1 张主视觉，16:9 自适应、页面居中 | 关键页、大图展示 |
| `duo` | 2 张并排 | 前后对比、两个状态 |
| `trio` | 3 张并排（引擎保留，当前演示未使用） | 多屏铺开 |
| `hero` | 3 张：左大图 + 右两张小图（引擎保留，当前演示未使用） | 主视觉 + 细节 |
| `flow` | 2 张上下错落（宽度 64% / 55%） | 节奏变化、避免呆板 |
| `note` | 1 个文字卡片（页面居中） | 关于我 |
| `gallery` | 大标题 + 通栏无限滚动跑马灯 + 富文本描述（标题距上一卡片 80px；`ratio:'portrait'` 竖版手机卡片） | OA「PC端其他页面」 |
| `tiles` | 大标题 + 富文本描述 + 通栏倾斜图片列网格，随滚动各列反向漂移并叠加自动呼吸（React Bits「Tilted Tiles」移植） | OA「移动端其他页面」 |
| `stack` | 大标题 + 富文本描述 + 滚动钉住卡片堆叠：相框式内嵌卡片，新卡垂直升起压顶（不旋转）、旧卡逐级上移压暗露出纸边层级；支持 1920×940 与 MP4（悬停播放 / 移出回第一帧）（React Bits「Scroll Stack」移植）；另支持 `badges` 徽章墙（APNG 原样播放，标题下 50px、一行 4 个、行距 30px、原始尺寸÷3） | 企业情感化运营视觉「动态主题登录页」+「徽章展示」 |

**素材统一按 1920×1080（16:9）准备**：所有卡片都是 16:9 且 `object-fit: contain`，
不会留白边、不会被裁切，也不会与左侧悬浮导航重叠（导航与卡片间距 ≥50px）。

### 2. 新增 / 删除 / 调整章节

```js
{
  id: 'app',                    // 唯一标识，会成为地址栏 #app
  label: '移动端 App',           // 左侧 Tab 中文名
  en: 'Mobile App',             // Tab 英文小字
  blocks: [                     // 一个区块 = 一屏，顺序即滚动顺序
    { layout: 'single', items: ['app-01.jpg'] },
    { layout: 'duo',    items: ['app-02.jpg', 'app-03.jpg'] },
    { layout: 'trio',   items: [
        { src: 'app-04.jpg', title: '首页',  desc: '主流程' },
        { src: 'app-05.jpg', title: '详情页' },
        { src: 'app-06.jpg', title: '个人中心' }
    ]}
  ]
}
```

- 章节顺序 = `sections` 数组顺序；删掉一个章节直接删数组元素即可。
- 每个区块还可以加标题：`{ layout:'single', title:'第 3 版方案', desc:'2025.06', items:[...] }`。
- Tab 右侧的角标数字自动统计该章节的素材数量。
- 作品的 `title / desc` **不再渲染到画面上**（卡片与灯箱角落均无文字），仅用于无障碍朗读与素材缺失时的兜底提示。

### 3. 通栏无限滚动跑马灯（layout:'gallery'）

结构（自上而下）：大标题（纯白 · 阿里妈妈数黑体 · 居中）→ 描述（距标题 24px · 居中）→
铺满窗口宽度的**匀速无限滚动**卡片跑马灯（参考 Hero 4「Infinite scrolling
video carousel marquee」模式）。标题距上方最后一个卡片 80px。

- 默认卡片 **1440×900（16:10）**，object-fit:cover 逐像素贴合、完美呈现不裁切；
  高 50vh（300~620px 自适应），整行通栏出血。配置 `ratio:'portrait'` 可切换为
  **手机竖版 750×1624**（高 58vh），用于移动端页面素材（如 OA「移动端其他页面」）。
- 左右边缘**不做渐隐/虚化**：卡片滚到窗口边缘直接裁切（纯净通栏出血）。
- **匀速连续滚动 + 无缝无限循环**：rAF 驱动 transform 位移，整组卡片复制填满轨道、
  位移按「一组宽度」取模回绕，回绕瞬间画面完全等价、肉眼无断层；
  悬停暂停 / 离开视口暂停 / 切走页签暂停，`prefers-reduced-motion` 关闭自动滚动。
- **可拖拽搓动**（按住左右拖，松手后自动恢复匀速滚动；拖拽不误触点击）；
  **点击卡片在灯箱放大预览**（与作品卡片同一套缩放/拖拽/键盘）。
- 卡片内不渲染任何文字提示（title 仅用于无障碍朗读与灯箱）；无切换箭头。

```js
{
  layout: 'gallery',
  title: 'PC端其他页面',
  items: [
    { src: 'oa-e10-01.jpg', title: '知识文档' },   // 共 6 张；title 仅用于无障碍朗读
    // ... 建议 1440×900（16:10），卡片即此比例、完美呈现
  ],
  desc: [                        // 在标题下方 24px、居中；字符串 = 50% 白；em = 100% 白 + 加粗
    { t: '【标准E10页面】', em: true },
    '基于E10标准组件库规范完成页面开发与扩展，',
    { t: '整体遵循系统统一交互、视觉风格', em: true },
    '；……',
    { t: '保证系统体验一致性', em: true },
    '。'
  ]
}
```

注意：画廊素材不计入 Tab 角标的作品数；跑马灯实现见 `js/carousel.js`
（rAF 匀速滚动 + 克隆补位取模回绕 + 拖拽），样式见 `css/carousel.css`。
大标题字体「阿里妈妈数黑体 Bold」（免费商用）已放在 `assets/fonts/`，
替换字体时把新文件丢进该目录并改 `css/base.css` 顶部的 `@font-face` 即可。

### 4. 滚动堆叠（layout:'stack'）

参考 React Bits Pro「Scroll Stack」（Pinned cards that stack, turn and
dissolve as the page scrolls）：大标题 + 富文本描述（与画廊同一套写法）
+ **钉住卡片堆叠**。区块高 = 视口高 + (N-1)×每卡行程 + 末张停留（`js/stack.js`
按视口 px 精确写入），内层 `.stack__viewport` 用 `position: sticky` 钉住一屏；
滚动进度换算成「当前顶卡序号 idx」，对每张卡按 d = idx − i 结算状态——

- **d < 0 待入场**：卡片在舞台下方等待，随滚动垂直升起、逐渐清晰（不旋转）；
- **d = 0 顶卡**：归位、清晰、上下双向重投影（`.is-active`），与身后卡片拉开层级；
- **d > 0 被覆盖**：逐级上移 46px/级、缩退（−4%/级）、模糊 + 压暗，顶缘亮线（`.is-covered`）露出「纸边」——每层都清晰可见，透明度不低于 0.5。

卡片为**相框式**结构（`--scard-inset: 8px` 内衬 + `overflow: hidden` 裁切 +
媒体内收圆角）——媒体真正「嵌」在卡片里，边框内衬清晰可见，不是铺满卡片的裸图。
卡片**不旋转**、保持端正；外框宽度公式与上方作品卡片完全一致
（`min(100%, var(--media-h) × 16/9)`，内容列内、超宽屏收敛 1760px），
比例 **1920×940**，`object-fit: cover` 逐像素贴合不裁切。层序按序号固定
（新卡恒在旧卡之上）；非顶卡 `pointer-events: none`，悬停/点击只命中顶卡。

**MP4 卡片**：items 混排视频（后缀识别，`.mp4/.webm/...` 自动走 video）。
默认 `preload="metadata"` 停在第一帧（加载后 seek 0.001s 强制出帧）；
**鼠标移入播放、移出暂停并回到第一帧**；卡片被覆盖 / 切走页签时同样复位，
不在看不见的地方继续解码；左上角 VIDEO 角标播放时淡出；点击仍可进灯箱。

数值量化 + 与上次相同则跳过写入；离开视口 / 切走页签暂停结算；
`prefers-reduced-motion` 时整块退化为静态纵向列表（`.is-static`）。
素材不计入 Tab 角标；大标题距上一卡片精确 80px（`syncGap()` 实测校正）。

```js
{
  layout: 'stack',
  title: '动态主题登录页',
  items: [
    { src: 'assets/video/manian-01.mp4', poster: 'assets/poster/manian-01.jpg' },
    'xn-04.png', /* 纯文件名 → 自动指向 assets/works/ */
  ],
  desc: [ '描述文字…' ]          // 同画廊：字符串 50% 白，{t, em:true} 100% 白加粗
}
```

### 5. 倾斜网格（layout:'tiles'）

参考 React Bits Pro「Tilted Tiles」：大标题 + 富文本描述（与画廊同一套写法）
+ 通栏高度受限的**倾斜图片列网格**。整组绕 Z 轴微倾（-12°）并放大铺满，
滚动时各列按不同速率、不同方向漂移（斜向流动的视差），并叠加一层极缓的
自动呼吸（有界正弦往复，不滚动时也保持微动）。区块经过视口的进度由
`js/tiles.js` 换算成每列的 translateY 逐帧写入；上下边缘有柔和的纵向渐隐，
四角化开进背景。素材按「每列等量 + 列间错位」分配，`tiles.js` 的 `ensureFill()`
再按实际视口尺寸与最大漂移行程自动克隆补齐——任意漂移状态下四角与四边都被
小图铺满，不会露背景；点击小图同样可在灯箱放大预览；`prefers-reduced-motion`
时漂移停用、网格静态呈现。
大标题距上方内容精确 80px（挂载时由 `tiles.js` 的 `syncGap()` 实测校正）。

```js
{
  layout: 'tiles',
  title: '移动端其他页面',
  columns: 9,                       // 列数（越多卡片越小越密；窄屏自动收窄为 3）
  items: [ 'app-e10-01.jpg', /* … */ ],   // 竖版素材 750×1624
  desc: [ { t: '强调文字', em: true }, '普通文字…' ]
}
```

注意：倾斜网格素材同样不计入 Tab 角标的作品数；实现见 `js/tiles.js`，
样式见 `css/tiles.css`。

### 6. 视频 / 动图混排

后缀 `mp4 / webm / mov` 自动识别为视频，`.gif` 自动识别为动图，其余按图片处理。

```js
{
  layout: 'single',
  items: [{
    src: 'assets/video/demo.mp4',        // 视频
    poster: 'assets/poster/demo.jpg',    // 封面（没有 poster 会显示第一帧）
    title: '交互动线演示',
    desc: '静音循环 · 点击放大播放',
    autoplay: true,   // 进入视口自动播放，离开自动暂停（默认 true）
    loop: true,       // 循环（默认 true）
    muted: true,      // 静音，浏览器才允许自动播放（默认 true）
    controls: false   // 是否显示控件（默认 false）
  }]
}
```

### 7. 首页全屏封面（MP4 / 动图 / 图片）

封面在 `config.js` 的 `home` 章节里配置，支持三种媒体：

```js
{
  layout: 'cover',
  media: {
    src: 'assets/cover/cover.mp4',            // 换成 cover.gif 即为动图，cover.jpg 即为静态图
    type: 'video',                            // 可省略（按后缀自动识别）
    poster: 'assets/cover/cover-poster.jpg'   // 视频封面兜底（编码不支持时显示）
  }
}
```

封面规则：**纯背景展示，不带文案**；媒体 `object-fit: cover` 铺满整个窗口（含左侧导航下方），
任何比例不变形；视频静音自动循环、不可播放时自动退回封面图。
建议 MP4 用 H.264/yuv420p、6~10s、体积 < 4MB。
（如需在封面上叠加文案，给 cover 区块加 `kicker / title / text / meta` 字段即可，引擎兼容。）

不想自动播放就把 `autoplay` 改成 `false`，此时只显示封面，点击后在灯箱里带控件播放。
`fill: true` 可以让图片「填满卡片并裁切」（默认 false，即完整显示不裁切）。

## 五、改主题与文案

| 想改什么 | 改哪里 |
| --- | --- |
| 背景色 / 文字色 / 点缀色 | `css/base.css` 顶部 `:root` 的 CSS 变量 |
| 毛玻璃模糊强度 | `--blur`、`--blur-strong` |
| 圆角大小 | `--r-sm` ~ `--r-xl` |
| 动效快慢与曲线 | `--dur-1`~`--dur-3`、`--ease` |
| 左侧导航宽度 | `--sidebar-w` |
| 单图最大高度 | `--media-h`（默认 `100dvh - 236px`） |
| 导航与卡片间距 | `--gap-nav`（默认 `50px`） |
| 卡片 hover 描边 | `--line-hover`（默认冷白 28%）+ `--dur-line` / `--ease-line`（描边缓动） |
| 站点标题 / 副标题 | `js/config.js` 的 `meta` |

## 七、性能设计说明

- **按需渲染**：切换章节时才创建该章节的 DOM，已渲染的章节会被缓存，切回是瞬时的。
- **图片懒加载**：`loading="lazy"` + 视口监听淡入，首屏只请求 1~3 张图。
- **单个观察器**：图片淡入与视频播放共用一个 `IntersectionObserver`，没有 `scroll` 循环重排。
- **轻量动效**：只做 `transform` / `opacity` 动画，不动画 `filter`、不用粒子特效，避免掉帧。
- **视频按需**：`preload="metadata"`，进入视口才播放，离开立刻暂停。
- **背景**：静态渐变 + 噪点贴图，零持续重绘。
- **自适应**：桌面优先，≤900px 转抽屉导航，≤640px 多图排版自动降级为纵向堆叠。

素材建议：单张压到 **800KB 以内**（长边 2000px 左右即可），视频控制在 **5MB / 10s** 内。

## 八、常见问题

**图片不显示？** 卡片上会显示「素材未找到」和它期望的路径，对照 `js/config.js`
里的文件名核对即可（注意扩展名与大小写）。

**页面打开了但没样式 / 没内容？** 确认 `css/`、`js/` 与 `index.html` 在同一层目录下，
文件夹结构不要打散。

**占位素材生成 / 校验脚本在哪？** 已从项目移出（部署包不含开发工具），
备份在项目上一级的 `.workbuddy/backup/prune-20260919/tools/`，需要时放回 `portfolio/tools/` 即可。

**能否导出成 PDF？** 打印样式已适配，浏览器 Ctrl+P 选「另存为 PDF」会把每个区块分页输出。
